# 操作、光学与验证

在浏览器里操作一台 4×5 技术相机。取景从完整毛玻璃开始，前组、后组、皮腔和光圈始终可以调节。切换到「机位」可观察同一套机构、摄影现场和物方焦平面。

## 本地运行

从[正式发布页](https://github.com/AliceMarskov/obscura-view-camera/releases)下载 HTML 文件，用支持 WebGL 2 的浏览器双击打开即可离线使用。巴黎街角、银盐工作间、冬园温室和光路校准台都在同一个文件里，可以单独复制或改名。

从源码重新生成单文件可运行 `npm.cmd run build:offline`，成品在 `dist/暗箱-大画幅取景台.html`。用 `node verification/standalone.mjs "dist/暗箱-大画幅取景台.html"` 可检查断网取景、调焦、校准与接片导出。

### 开发预览

使用 Node.js 24 与支持 WebGL 2 的浏览器，在项目目录运行以下命令。

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run dev
```

打开[本地取景台](http://127.0.0.1:5173/)或[光路校准台](http://127.0.0.1:5173/calibration.html)。`npm.cmd run build` 会检查 TypeScript 并生成可交给静态 HTTP 服务的 `dist/`。几何模型、照片、纹理和脚本随应用提供。

## 用街角建筑试一次移轴

默认的「巴黎 · 奥斯曼街角」模拟从人行道仰拍书店。近处街灯约 4 m，主楼距镜头约 22 m，立面宽 23.8 m，檐口高 16.7 m。90 mm 广角镜头和整机 19° 仰角让高处的窗列明显向内收。

1. 打开「网格」，比较左右窗列与毛玻璃上竖线的夹角。
2. 选「皮腔 / 整机」的「整机俯仰」，从 19° 调回 0°。建筑的竖线重新平行，原本纳入画面的屋顶会移高。
3. 选「前组」的「升降」，向上移约 31 mm，把立面重新纳入。在同一组相距 22 m 的竖线上，离地 0.5 m 和 16.5 m 处的片面横间距从约 95.4 / 76.0 mm 变为 88.9 / 88.9 mm，楼面中心的片面高度只改变约 0.2 mm。
4. 点「机位」观察整个装置。拖空白处环绕相机，拖前组或后组可操作所选自由度，拖对焦轨可伸缩皮腔。移动观察视点只影响三维观察窗。整机旋转会同时改变镜头、后背与毛玻璃构图。

切到「光路侧视」，打开「光线」。每对金色光线从同一个片上采样点穿过光圈对边，示意范围内的离轴会聚点会落在绿色焦面上。轴上、无穷远、虚焦和示意范围外的情况按实际共轭关系处理。侧视与俯视中光路可透过建筑观察；地面网格和示意光线只在机位窗显示。

巴黎默认镜头为 90 mm，皮腔为 90.38 mm，只转动后组时，轴上合焦位置距镜头约 21.4 m。后组 −18° 至 +18° 的全程让物方焦面连续转过约 178.5°。在后组 −0.10°、0°、+0.10° 三处，焦面与镜头板的较小夹角分别为 22.46°、0°、22.46°，方向可在侧视图中辨认。在这套居中、仅后组俯仰的设置下，夹角大小满足 tan β = f |tan α| / (v − f)，其中 α 为后组俯仰角，v 为皮腔长度。后组轴倾时，片面旋转轴对应的物方合焦线固定。[Merklinger 的后组轴倾示意（图 6）](https://lensnotes.com/articles/principles-of-view-camera-focus/)

## 看着毛玻璃调焦

- **放大和扫视。** 1× 显示全片，点画面可从该处进入 2×，也可用 1×、2×、4× 切换倍率。放大后，鼠标或手指拖动画面会带着影像走，点另一处可以重新居中。放大区域在真实片幅边缘停止。回到 1× 可以复核最终构图。
- **峰值、网格与正像。** 「峰值」用红色标出有效景深内足够清晰的纹理边缘。平滑墙面即使合焦，也可能没有峰值。网格在片面上每 10 mm 一条白细线，附中心十字和 6×9 片幅角标（教学取景范围 84 × 56 mm）。放大镜会同时放大刻线。首次使用默认上下、左右倒像，「正像」开关可将图像翻正。刻线设计参考实物对焦屏的厘米分格和多片幅标示。[Linhof 多片幅毛玻璃](https://linhof.com/en/multiformat-mattscheibe/) · [ARCA-SWISS 4×5 对焦屏](https://arca-swiss-usa.com/products/ground-glass-screen-4x5)
- **全开和收光圈。** 开启「全开对焦」后按镜头最大孔径取景，适合判断细节最清楚的位置。再次按下可回到选定的工作光圈，检查景深的变化。可以在静物场景轮流放大近处药瓶的纸标和后方照片，交替用前组俯仰与皮腔寻找同时合焦的位置。
- **片夹方向。** 旋转后背将 120 × 96 mm 的取景范围换成 96 × 120 mm，光学计算随片幅更新。前、后组已有的俯仰和摆动继续按各自机构生效。
- **接片。** 在「接片」记录第一张，关闭取样窗，只调后组横移，再打开取第二张。镜头、后背方向、皮腔、光圈与片幅应保持一致，两次取景须有重叠，后组摆动设为 0°。例如横幅后组从 −24 mm 移到 +24 mm，重叠 72 mm，合成 168 × 96 mm。两次取样都保存完整片面，网格、红色峰值和放大镜只用于观察。
- **固定测点与印样。** 放大后点「钉住 A」，再拖动放大镜观察 B。两个窗口都随相机设置更新。「印样」可保存带拍摄参数的全片正像，并选择彩色、银盐黑白或铂金印相色调。

电脑横屏并排提供毛玻璃、三维观察与调节区。手机竖屏把当前观察窗放在上方，调节区放在下方，可以在毛玻璃和机位之间切换。

### 滚轮与精确输入

选择一枚参数键后可在下方共用的宽幅滚轮上操作。常规布局同时显示其余参数的当前值，较矮的手机用一排紧凑参数键腾出取景空间，选中值始终在滚轮上方。左右拖动使用相对增量，按下滚轮时保持原值。

| 操作 | 调整方式 |
| --- | --- |
| 点按或拖底部全行程刻度 | 直接定位到两个机械端点之间的任意位置 |
| 粗调档左右拖动滚轮 | 100–240 px 的行程对应整个参数范围，随面板宽度设定 |
| 精调档左右拖动滚轮 | 每 8 px 调一个最小刻度。皮腔为 0.01 mm，移轴为 0.1 mm，前后组角度为 0.01°，整机角度为 0.1° |
| 按住 Shift 拖动 | 暂时使用精调传动，可在拖动中途切换 |
| ± 或方向键 | 一次调整一格，光圈按镜头实际档位停靠 |
| 点击数值 | 直接输入，回车或失焦应用，Esc 撤回草稿 |
| Page Up / Down、Home / End、双击滚轮 | 分别调十格、到行程端点、恢复当前参数初值 |

桌面和触屏都能显式切换粗、精调档。设计参考了成熟软件中拖动连续数值、临时降低灵敏度和直接输入的组合，再按对焦轨的实际单位设定传动比。[Blender 数值字段](https://docs.blender.org/manual/en/latest/interface/controls/buttons/fields.html) · [Adobe After Effects 属性控件](https://helpx.adobe.com/after-effects/desktop/work-with-layers/layer-properties/layer-properties.html)

## 可复算的光学模型

长度采用毫米。+X 向右、+Y 向上，未转动的镜头朝 −Z 摄影。L 是镜心，B 是感光面中心，n 和 m 是镜头、感光面朝后的单位法向。对于物点 P，令 X = P − L，轴向物距 u = −n·X，感光面的法向间距 d = m·(B − L)。

- **投影与焦平面。** 主光线在感光面上的交点为 L + X d/(m·X)。焦距为 f 时，理想共轭像位于 L − f X/(u − f)。令共轭像落在片上，得到物方清晰面 **(f m − d n)·X = f d**。镜头与感光面不平行时，二者的延长面与物方清晰面交于同一直线。
- **校准。** 平行组满足 1/f = 1/u + 1/v。对 f = 150 mm 的镜头，v = 174 mm 对应 u = 1087.5 mm，v = 150.01 mm 对应约 2250 m，v = f 对应无穷远。独立校准台可通过端点和精调旋钮观察这些边界。
- **孔径与景深。** 从镜心到片面采样点的向量为 R，圆形孔径内的偏移为 A。反向光线从 L + A 出发，方向为 −R + A(1 − n·R/f)。每个孔径点对应一个离轴投影视锥。对单个物点，取 12 对相对孔缘光线的片上交点，最大对径为弥散斑的直径估计。平行组还可用 c = (f/N)|1 − d/v| 复算。轴上景深在倒物距空间求解 c = 0.10 mm 的近、远界，远界可达无穷。
- **离轴景深与交线。** 在侧视或俯视打开「景深」，近界和远界是穿过片幅中心的竖向或横向截面上，片上弥散斑最大对径恰好达到 0.10 mm 的位置。收小光圈可扩大允许区域。超出场景与像圈的部分经裁切，无穷远处按投影坐标连续处理。「光学平面」在实物表面标出精确合焦交线，按观察位置自然遮挡。
- **铰链线与沙姆交线。** 镜头平面和感光面不平行时，两者与物方焦面共有沙姆交线。铰链线位于物方前焦平面与过镜心且平行感光面的辅助平面的交界，它也在物方焦面上。镜头板与片面法向夹角为 θ 时，铰距 J = f / |sin θ|。两组平行时交线退至无穷远。
- **峰值。** 用中央光线的深度恢复可见表面，将每个像素预计的片上弥散圈与 0.10 mm 比较，再由局部亮度梯度生成红色轮廓。接近允许弥散圈的边界会逐渐淡出，跨越前景和背景的深度跳变会抑制假边缘。平坦、低反差的合焦表面仍可通过局部放大核对。
- **清晰度参照。** 放大区域可切换为镜心光线成像，以四个片面子像素采样消除锯齿。两种显示的取景范围、光照和边缘失光一致。切回真实孔径即可逐处核对离焦造成的细节损失。接片使用全片范围和实际孔径。
- **照度与像场。** 相对于同光圈、无限远合焦时的轴上照度，理想平面出瞳给出 E = f² max(0,n·R) max(0,m·R) / |R|⁴。在平行组上，和同一底片中心相比衰减为 cos⁴θ，增加皮腔伸长还会降低轴上照度。像场另按圆锥覆盖计算，半角满足 tan α = C/(2f)，C 为标称无限远像圈直径。四角的最大归一化半径给出「像场利用率」，超过 100% 时角部超出覆盖。
- **放大与积分。** 1× 对应全片，2×、4× 分别把宽高各缩至 1/2、1/4，且在片面坐标内约束放大区域。拖动时快速预览，停下后按当前区域重新投影。调整机构后的首帧用表面深度和弥散椭圆预览，随后在整个孔径的线性光强样本上累积。从第 17 个样本起只显示孔径积分，浮点设备按场景和倍率使用 64–192 个样本，低动态范围回退使用 48 个。

当前模型适合解释几何成像、离焦、相对照度和像圈。成像采用无厚度的理想近轴透镜，全开时使用圆孔、收小后按等面积七边形孔径积分。教学景深维持标称圆孔的 12 对孔缘定义。毛玻璃颗粒和印样色调属于显示效果，模型省略像差、衍射、曝时、实测感光曲线与机构碰撞。有限孔径采样在极端虚化时可能可见颗粒。[OpenStax 薄透镜](https://openstax.org/books/university-physics-volume-3/pages/2-4-thin-lenses) · [H. M. Merklinger《Focusing the View Camera》](https://www.cs.cmu.edu/~ILIM/courses/vision-sensors/readings/FVC16.pdf)
